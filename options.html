Facebook Feed Filter

Each rule contributes a score when it matches a post. A post is filtered when the total score reaches the threshold. Changes take effect immediately on any open Facebook tab.

A title is hidden when the sum of its rule scores is ≥ this value.

Rule schema

Each rule has a name, a type, a weight (number; how much it contributes to the score), and type-specific fields. enabled defaults to true. Regex / caps / emoji rules run against the post's message-preview text; selector / text_selector rules run against the post DOM.

  • { "type": "regex", "pattern": "...", "flags": "i", "weight": 0.4 } — adds weight if the regex matches the post text. Add "perMatch": true for per-match scoring.
  • { "type": "caps_ratio", "threshold": 0.7, "minLetters": 15, "weight": 0.5 } — adds weight if more than threshold of the post text's letters are uppercase.
  • { "type": "emoji_count", "threshold": 3, "weight": 0.4 } — adds weight if the post text contains at least threshold emoji.
  • { "type": "selector", "selector": "a[href*='l.facebook.com/l.php']", "weight": 1.0 } — adds weight if any descendant of the post matches the CSS selector. Used to flag sponsored posts (they use Facebook's external-redirect domain).
  • { "type": "text_selector", "selector": "h4 div[role='button']", "text": "Follow", "weight": 1.0 } — adds weight if any element matching the selector has trimmed text equal to text (case-insensitive). Optional "matchType": "contains" or "startsWith" changes the comparison; default is exact match. Used to flag posts from pages you don't follow (visible "Follow" button).

Remember to double-escape backslashes in JSON (e.g. \\b, \\?).
