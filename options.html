Clickbait Filter

Each rule contributes a score when it matches. A card is filtered when the total score reaches the threshold. Changes take effect immediately on any open YouTube tab.

A title is hidden when the sum of its rule scores is ≥ this value.

Rule schema

Each rule has a name, a type, a weight (number; how much it contributes to the score), and type-specific fields. enabled defaults to true.

  • { "type": "regex", "pattern": "...", "flags": "i", "weight": 0.4 } — adds weight if the regex matches at least once. Add "perMatch": true to instead add weight × match_count (useful for per-character scoring like exclamation points).
  • { "type": "caps_ratio", "threshold": 0.7, "minLetters": 15, "weight": 0.5 } — adds weight if more than threshold of the title's letters are uppercase (with a minimum letter count).
  • { "type": "emoji_count", "threshold": 3, "weight": 0.4 } — adds weight if the title contains at least threshold emoji.

Remember to double-escape backslashes in JSON (e.g. \\b, \\?).
