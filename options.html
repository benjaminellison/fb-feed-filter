Clickbait Filter

Edit the rule list as JSON. Changes take effect immediately on any open YouTube tab.

Rule schema

Each rule is an object with a name, a type, and type-specific fields. enabled defaults to true if omitted.

  • { "type": "regex", "pattern": "...", "flags": "i" } — matches title against a regex. Remember to double-escape backslashes in JSON (e.g. \\b).
  • { "type": "caps_ratio", "threshold": 0.7, "minLetters": 15 } — matches if more than threshold of the title's letters are uppercase, with a minimum letter count.
  • { "type": "emoji_count", "threshold": 3 } — matches if the title has at least threshold emoji.
